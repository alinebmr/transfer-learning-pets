# Classificação de Raças de Gatos e Cães — Transfer Learning com PyTorch

Pipeline de visão computacional para a classificação de raças de animais utilizando técnicas de Transfer Learning com PyTorch e o Oxford-IIIT Pet Dataset.

---

## 📋 Sobre o Projeto
O objetivo deste projeto é estruturar um pipeline em PyTorch para a preparação e carregamento de dados voltado à classificação de raças de animais. O fluxo abrange o pré-processamento das imagens, divisão dos dados e a configuração dos carregadores de dados (`DataLoaders`).

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
- Python
- PyTorch & Torchvision
- Matplotlib
