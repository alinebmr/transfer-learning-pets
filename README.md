# Classificação de Raças de Gatos e Cães — Transfer Learning com PyTorch

Pipeline completo de visão computacional para a classificação de raças de animais utilizando técnicas de *Transfer Learning* com PyTorch e o conjunto de dados **Oxford-IIIT Pet Dataset**.

---

## 📋 Sobre o Projeto
O objetivo deste projeto é treinar, avaliar e comparar o desempenho de diferentes arquiteturas de redes neurais profundas na tarefa de classificação fina de raças de animais. O fluxo abrange desde o pré-processamento das imagens e particionamento dos dados até à configuração dos carregadores de dados (*DataLoaders*) para o treino dos modelos.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Python**
* **PyTorch** & **Torchvision**
* **Matplotlib**
